Welcome to the HerbivoR installer.

After this Setup finishes copying files, a second window will open to:

  1. Install a private Python runtime if needed (you do not need to install Python yourself)
  2. Detect an NVIDIA GPU and install the matching PyTorch build
  3. Install application libraries
  4. Download model weights (~226 MB)
  5. Create a Desktop / Start Menu shortcut with the leaf icon

You need an internet connection. The dependency step usually takes 5–20 minutes.

On Windows PCs without an NVIDIA GPU, CPU mode is selected automatically.
