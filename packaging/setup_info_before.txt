After files are copied, Setup will automatically:

  1. Install a private Python runtime with Tcl/Tk (you do not need Python yourself)
  2. Detect an NVIDIA GPU and install the matching PyTorch build
  3. Install application libraries
  4. Download model weights (~226 MB)
  5. Create shortcuts with the leaf icon

Please wait — this step needs internet and usually takes 5–20 minutes.
Do not close the console window until it finishes.

On PCs without an NVIDIA GPU, CPU mode is selected automatically.
